# Glossary — Device LEGO

| Termo | Significado |
|-------|-------------|
| HalOffer | API R3→R1 query/bind (não é VirtIO) |
| VirtIO | Transporte BE; produto continua HalOffer |
| L0/L1/L2 | Bus / Port / DeviceRecipe |
| UnlockDAG | Grafo de stages com requires/provides |
| Partial | Stage incompleto honesto (≠ Ready) |
| blob_hash | Hash do FW citado na recipe |
| device-recipe | Kind PackageHub em `ecosystem/devices/` |
| FatReadable | Token: blobs acessíveis (ATA ou UsbMsc) |
| AWAITING_REAL_HW | Aceite só em silício / serial |
