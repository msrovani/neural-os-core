# v2.0 — Sequência de implementação P0 → P1 → P2

**Aceite transversal (o fio condutor):** ao fim de cada fase, o runtime **NÃO pode
travar com `#PF`, `#DF` ou `#TF`** — um fault vira **reboot ordenado observável**
(`[RECOVER] reason=` no BOOT.LOG) ou **contenção** (`fault-contained`), nunca
`loop{hlt}` mudo. Fechadas as 3 fases → **v2.0**.

Regra OPCODE/1 + ADR-0113: cada item fecha com **evidência de runtime** (log/
SESSION), `cargo build --release -p boot` 0 erros, testes host, e registro
(TODO/SESSION/STATE). `n/a ≠ 0`; `IMPLEMENTED ≠ OBSERVED`.
